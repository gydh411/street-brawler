## 2. 敌人：七档奶龙

```js
n1 黄   hp 30   speed 92   dmg 7   scale 0.88   wind 0.34   cool 1.15   score 80
n2 绿   hp 44   speed 100  dmg 9   scale 0.94   wind 0.32   cool 1.05   score 120
n3 青   hp 60   speed 112  dmg 11  scale 1.00   wind 0.30   cool 0.95   score 170
n4 蓝   hp 82   speed 122  dmg 14  scale 1.08   wind 0.28   cool 0.85   score 240
n5 紫   hp 110  speed 132  dmg 17  scale 1.16   wind 0.26   cool 0.78   score 330
n6 红   hp 260  speed 118  dmg 21  scale 1.30   wind 0.28   cool 0.80   score 1400   BOSS
n7 橙   hp 420  speed 134  dmg 25  scale 1.44   wind 0.24   cool 0.70   score 3200   终极 BOSS
```

- `wind`：出手前摇时长，越小越难反应。
- `cool`：出手后的冷却基数，实际值再乘 `rnd(0.5, 0.8)`。
- 触及距离 `reach` 46 ~ 68，随档位递增。
- n5 及以上头顶绘制光环，n6 / n7 在屏幕上方显示独立血条。

### 关卡配置

```js
第一关 旧城区·后巷      hp 100   3 波   n1,n1,n2,n1 → n1,n2,n1,n2,n1 → n2,n1,n3,n2
第二关 霓虹街·夜市口    hp 108   3 波   n2,n2,n3,n2 → n3,n2,n4,n2,n3 → n4,n3,n3,n2
第三关 黑虎帮·堂口      hp 120   3 波   n3,n4,n3,n5 → n4,n4,n5,n3,n3 → n6,n5,n4,n5
第四关 黑虎帮·顶层决战  hp 130   2 波   n5,n4,n5,n3 → n7,n5,n4,n5
```

每一波刷怪时随机分配左右两侧，若全部落在同一侧则把最后一个翻到另一侧，保证包夹。BOSS 固定在画面内右侧 `cam.x + W - 150` 登场，不会出现"血条出来了人还没走到"。

## 3. 敌人 AI 状态机

```
chase ──接近到攻击距离──▶ wind ──前摇结束──▶ strike ──▶ chase
  │                        │
  └──远距离且冷却好──▶ dash ┘
任意状态受击 ──▶ hurt ──▶ chase
受到击倒类攻击 ──▶ down ──▶ chase
HP <= 0 ──▶ dead
```

| 状态 | 行为 |
| --- | --- |
| `chase` | 绕向玩家侧后方，保持站位距离；随机微调纵深避免重叠；`walkPhase` 按实际位移推进，脚不打滑 |
| `wind` | 前摇：持续面向玩家并小幅贴近，姿态后仰拉弓；同时决定这一击用 `punch` 还是 `kick`（重型/BOSS 45%，普通 22%） |
| `strike` | 出手：在 0.20 s 窗口内**逐帧**判定命中，命中一次即止 |
| `dash` | 冲锋：远距离突进，途中逐帧判定，命中盒放宽 |
| `hurt` | 受击后仰抖动，短暂硬直 |
| `down` | 击倒翻滚，起身后回 `chase` |
| `dead` | 倒地压扁淡出 |

### 命中判定

- 纵轴统一用 `(player.y + e.offY) - e.y`，阈值 46 px —— 之前漏算 `offY` 导致经常打不到。
- 横向阈值 = `reach + 14`。
- 出手窗口内逐帧检测，而不是只取某一帧快照。
- 进攻权：场上同时最多 3 人出手；同侧则必须等到当前没人进攻才放行，所以不会出现一堆人挤在同一侧轮流贴脸。

## 4. 奶龙骨骼动画

### 拆件

源图 1220 × 1552（白底 JPEG），逐像素分类：

| id | 部件 |
| --- | --- |
| 0 | 身体（含头、肚皮） |
| 1 | 左上臂 |
| 2 | 左前臂 |
| 3 | 左大腿 |
| 4 | 左小腿 |
| 5 | 右大腿 |
| 6 | 右小腿 |

躯干边界靠米色肚皮判定：`b > 118 && r - b > 28 && g - b > 16 && r > 190`。
每个部件裁成独立 canvas，关节处再生成软径向补片（髋 L/R、肩 L）盖住接缝。

### 关键锚点（源图坐标）

```js
hipL   [452, 1092]    kneeL [385, 1268]
hipR   [908, 1092]    kneeR [1015, 1268]
shL    [372, 548]     elbowL [206, 462]
legTop 1080   centerX 610   armX 386
```

### 姿势参数

| 参数 | 含义 |
| --- | --- |
| `lean` | 躯干前倾角 |
| `bob` | 上下起伏 |
| `lunge` | 横向前冲位移 |
| `sink` | 下蹲量 |
| `hipL / kneeL / hipR / kneeR` | 左右大腿、小腿角度 |
| `shL / elbL` | 肩、肘角度 |

走路循环：

```js
hipL  = 0.46 * sin(ph);
kneeL = -0.55 * max(0, cos(ph));
```

配合双臂反向摆与身体起伏，形成完整步态；`ph`（`walkPhase`）由位移驱动。

直拳（`pose: 'punch'`）：后仰蓄力 → 躯干前倾 + 手臂推出。
正蹬（`pose: 'kick'`）：提膝 → 展小腿前蹬。

### 绘制顺序

```
双腿 → 关节补片 → 身体 → 手臂
```

这样摆腿摆臂时不会露出身体被挖空的位置。

## 6. 调参建议

- **想更简单**：把 `EDEF` 里 `wind` 调大（前摇更长，好反应），或降低 `dmg`。
- **想更硬核**：减小 `wind`、缩短 `cool`，同时提高 `player.maxHp` 避免被秒。
- **想更耐打**：只调 `hp`，不要动 `scale`，否则视觉上会比实际强度更吓人。
- **改敌人数量**：直接改 `STAGES[].waves` 数组，每个字符串是一个敌档。
