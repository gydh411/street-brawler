# Street Brawler 街头霸王 · 闯关格斗

一款纯 HTML5 Canvas 实现的街头格斗闯关游戏，**单文件、零依赖**，浏览器打开即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可（也支持部署到 GitHub Pages）。

## 游戏特色

- **三关闯关**：街头 → 小巷 → 码头，每关敌人配置不同，最终关有 BOSS 战
- **四种敌人**：小混混、快刀手、壮汉、BOSS，各有独立 AI（游走、突进、霸体）
- **真人动作系统**：基于双骨骼 IK（逆运动学）的姿态驱动动画，出拳/踢腿遵循「蓄力 → 转髋发力 → 收招」的真实发力规律
- **三连击连招**：刺拳 → 后手直拳 → 上勾拳，第三击附带击退
- **必杀技**：能量满后释放旋风腿，范围高伤
- **打击感**：命中火花、屏幕震动、顿帧、飘字伤害、受击闪光
- **触屏支持**：手机横屏虚拟摇杆 + 按键，自适应布局

## 操作方式

| 按键 | 动作 |
|---|---|
| ← → / A D | 移动 |
| ↑ / W | 跳跃 |
| ↓ / S | 格挡 |
| J / Z | 拳（连按出三连击） |
| K / X | 踢 |
| L / C | 必杀（能量满时） |

## 技术要点

- 单文件实现：HTML + CSS + 原生 JavaScript，无任何外部依赖
- 自研骨骼动画：IK 解算四肢关节，目标点插值 + 缓动函数生成动作曲线
- 游戏循环：固定时步逻辑、视差滚动背景、敌人分离与站位算法
- 调试彩蛋：URL 加 `#lab` 进入动作实验室，可逐帧校对任意姿势

## 本地运行

```bash

# 方式二：起个本地服务器
```
